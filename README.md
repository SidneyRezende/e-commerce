# Projeto Banco de Dados – E-Commerce

## Descrição do Projeto

Este projeto apresenta a modelagem lógica de um banco de dados para um sistema de e-commerce.

Foram aplicados conceitos de:
- Modelo EER
- Especialização (Cliente PF e PJ)
- Mapeamento para modelo relacional
- Definição de PK e FK
- Constraints (CHECK, UNIQUE, NOT NULL)
- Consultas SQL com SELECT, WHERE, GROUP BY, HAVING, ORDER BY
- Atributos derivados
- Junções entre tabelas

## Estrutura do Projeto

- schema.sql → Criação das tabelas
- inserts.sql → Inserção de dados de teste
- queries.sql → Consultas SQL implementadas

## Tecnologias Utilizadas

- PostgreSQL
- SQL
- Git e GitHub
